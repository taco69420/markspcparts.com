Pulled from a working system and confirmed fully operational — booted to BIOS clean, both CPUs identified correctly, all memory slots verified, no Q-code errors.

Full onboard IPMI/BMC (ASMB8-iKVM) — dedicated management port, out-of-band remote access via web browser. KVM over IP, remote power on/off/reset, hardware monitoring, fan control, BIOS access over the network. No extra hardware needed. Proxmox and homelab builders know exactly what this means.

Upgrade path goes all the way to E5-2699 v4 (22-core) in both sockets — the included E5-2620 v4s prove the platform works, and you can drop in whatever v3 or v4 Xeons you want from there.
